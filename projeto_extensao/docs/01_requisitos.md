# Requisitos — Conecta Gerações

## Funcionais
- RF01: cadastrar participante.
- RF02: listar participantes.
- RF03: consultar os quatro encontros do projeto.
- RF04: consultar material didático por encontro.
- RF05: registrar presença.
- RF06: registrar nível de aprendizado de 1 a 5.
- RF07: registrar observações do monitor.
- RF08: exibir indicadores básicos no painel.

## Não funcionais
- RNF01: interface responsiva para computador e celular.
- RNF02: persistência local em SQLite.
- RNF03: interface em português do Brasil.
- RNF04: formulários com validação básica.
- RNF05: arquitetura simples e de fácil manutenção para fins acadêmicos.
- RNF06: não armazenar dados sensíveis desnecessários.
