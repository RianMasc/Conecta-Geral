# Cuidados com dados dos participantes

O projeto deve coletar somente dados necessários à execução e avaliação da atividade. Antes de publicar screenshots, vídeos ou documentos, o grupo deve verificar se há nomes, telefones, e-mails, imagens ou outras informações identificáveis que não devam ser divulgadas. Solicitar autorização conforme as regras da instituição para registros de imagem e uso acadêmico.
