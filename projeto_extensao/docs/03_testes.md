# Plano de Testes e Resultados

Os testes automatizados incluídos verificam carregamento da aplicação e cadastro de participante.

## Matriz para validação final

| Caso | Resultado esperado | Resultado real | Status |
|---|---|---|---|
| Acesso inicial | Dashboard abre | Preencher após execução | A validar |
| Cadastro de participante | Registro salvo | Preencher | A validar |
| Cadastro com idade < 60 | Aviso ao monitor | Preencher | A validar |
| Registro de acompanhamento | Registro salvo | Preencher | A validar |
| Material de encontro | Conteúdo correto exibido | Preencher | A validar |

Não devem ser inventados resultados da ação de extensão. Depois da execução real, substituir “A validar” pelos resultados observados.
