# Checklist antes da entrega

- [ ] Substituir nomes e RAs pelos integrantes reais em ordem alfabética.
- [ ] Conferir professor/orientador e ano.
- [ ] Confirmar título definitivo.
- [ ] Inserir local, datas e informações reais da ação de extensão.
- [ ] Inserir prints reais da aplicação.
- [ ] Inserir diagramas finais.
- [ ] Executar os testes e preencher resultados reais.
- [ ] Realizar a ação de extensão e registrar evidências permitidas.
- [ ] Aplicar questionário aos participantes, se exigido pela orientação.
- [ ] Inserir link real do vídeo no YouTube.
- [ ] Revisar referências conforme ABNT.
- [ ] Gerar sumário automático no editor de texto.
- [ ] Revisar ortografia e formatação conforme o padrão solicitado pela professora.
