# Conecta Gerações — versão 2.0

Interface renovada para o projeto de extensão em inclusão digital.

## Executar no Windows
1. Abra a pasta `projeto_extensao`.
2. Execute `run_windows.bat` ou abra um CMD nessa pasta.
3. Rode `python -m pip install -r requirements.txt` (primeira vez).
4. Rode `python app\\run.py`.
5. Acesse `http://127.0.0.1:5000`.

## Funcionalidades
- Dashboard com indicadores e atividade recente.
- Cadastro, busca, edição, exclusão e perfil de participantes.
- Quatro encontros e materiais didáticos.
- Registro de presença e aprendizado.
- Indicadores consolidados e impressão do relatório.
- Controles de acessibilidade: fonte ampliada e alto contraste.
- Layout responsivo para telas menores.

Os indicadores são calculados somente a partir dos dados registrados no sistema; resultados reais da extensão devem ser preenchidos após a execução das atividades.
